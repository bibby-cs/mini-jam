Game Assets

No external art, sprites, textures, music, or sound effects were used.

The game’s visuals are drawn using Raylib primitives such as circles, rectangles, lines, and text.

Libraries

The game uses:

* Odin
* Raylib through Odin’s vendor:raylib package

These libraries are dependencies of the provided course environment.

Original Work

The game design, gameplay rules, tuning values, and game code were created for the CSCI 4160U Mini Game Jam.

The game is based on the course-provided ARENA starting point and was modified into BLEED ARENA.
